Recipe Suggester

Type your ingredients or set a time limit, filter by diet, and we’ll match recipes from your recipes.json. Optionally, ask Gemini to invent recipes.
Tips
  • Place recipes.json in the same folder as this HTML file.
  • Ingredient matching is flexible; we score by overlap.
  • “Use AI” asks Gemini for JSON recipes (we validate & render them).
  • Don’t expose real API keys publicly — this demo keeps it in localStorage only on your device.
